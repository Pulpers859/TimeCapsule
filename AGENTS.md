# Agent Instructions

## Swift Automation

Before changing CI, tests, workflows, or other automation, use the current [Swift Agent Automation Kit](https://github.com/Pulpers859/swift-agent-automation-kit) and read both `.swift-automation.json` and `docs/AUTOMATED_TESTING_HANDOFF.md`. Preview and validate automation-kit changes before applying them, preserve the documented security and platform boundaries, and update the handoff with new evidence after material automation changes.
